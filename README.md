# Portfólio Pessoal

Landing Page desenvolvida em React + Vite para apresentar minha trajetória profissional, tecnologias, projetos e certificados.

---

## Sobre

Este projeto foi desenvolvido com o objetivo de reunir em um único lugar todas as informações relevantes sobre minha carreira como Desenvolvedor Backend em formação.

O portfólio apresenta minhas habilidades, experiências, projetos desenvolvidos, certificações e formas de contato, servindo como uma vitrine profissional para recrutadores e empresas.

---

## Funcionalidades

- Página inicial moderna
- Apresentação profissional
- Seção Sobre
- Tecnologias
- Projetos
- Experiência Profissional
- Formação Acadêmica
- Certificados com download em PDF
- Contato
- Layout responsivo
